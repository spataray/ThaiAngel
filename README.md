# ThaiAngel 😇

Age verification tool and screensaver for T.A. Station with bilingual (EN/TH) support.

## 🌟 Features
- **Age Verification**: Simple gatekeeper for age-restricted venues.
- **Bilingual Support**: Full English and Thai translations.
- **Screensaver Mode**: Beautiful, ambient display for when the system is idle.
- **Gallery**: Photo gallery for venue promotion.

## 🚀 Quick Start
- Open `index.html` in any modern web browser.
- For screensaver only, open `screensaver.js` (or the associated HTML if applicable).

## Development

- `npm run lint`: Runs ESLint and Stylelint to ensure code quality and ES5 compatibility. This is crucial for maintaining hardware compatibility with older smart TVs and early Android tablets.
